Funcionalidades Cross-Page

Independente do layout visual, estes comportamentos melhoram a análise:

Sync Global

Filtros persistem via sessionStorage ao navegar entre páginas. Cada página reage ao evento filters:change.

Contagem de Resultados

Badge mostrando "23 de 96 distribuidoras" para feedback imediato do impacto dos filtros.

Deeplink / URL Params

Salvar filtros na URL (?grupos=neo,cpfl&porte=GG) para compartilhar análises específicas.

Presets Rápidos

Atalhos: "Só Neoenergia", "Top 5 holdings", "Distribuidoras GG" — 1 clique aplica um conjunto de filtros.
