Sidebar slim (ícones), KPIs pareados (pré × pós com delta), painel de insights ao lado dos charts, barra de filtros ativos. Máxima densidade de informação para análise.

C. Storytelling Analítico

Hero com conclusão principal no topo, charts com anotações contextuais (marco REN 1000), narrativa guiando o olhar. Ótimo para apresentação de TCC, mas menos flexível para exploração livre.

Comparação Rápida

Forças de cada abordagem

  • A (Polish): Menor risco, mantém o que funciona, rápido de implementar
  • B (Denso): Máxima info por pixel, KPIs pareados pré/pós, painel de insights
  • C (Story): Hero com conclusão, anotações contextuais, ideal para defesa de TCC

Tradeoffs

  • A: Não resolve a falta de agrupamento pré/pós e insights automáticos
  • B: Mais complexo, pode ficar denso demais em telas menores
  • C: Menos flexível para exploração livre, mais "apresentação" que "ferramenta"
